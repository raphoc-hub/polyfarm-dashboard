# PolyFarm — Quant Dashboard

Live quantitative trading dashboard for the PolyFarm automated prediction market system. Tracks portfolio performance, open positions, real-time edge calculations, and decision history across Polymarket.

## Features

- **Portfolio Overview** — Starting capital, current cash, unrealized P&L, total equity
- **Open Positions** — Real-time bet tracking with entry price, estimated probability, edge, and potential payout
- **Decision Feed** — Chronological log of all trading decisions with reasoning
- **Model Confidence** — Edge calculations and conviction scoring per position
- **Dark Theme** — Brutalist-luxury design with Chart.js visualizations

## Tech

- HTML/CSS/JS (single-page)
- Chart.js for data visualization
- GitHub Pages deployment
